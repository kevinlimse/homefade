# homefade

Wall-mounted motorized fader for Home Assistant (brightness / colour temp, live two-way sync), 18 mm pitch so 2–3 sit side by side.

- `HANDOVER.md` – status, chosen parts, open items, how to set up a new machine.
- `pcb/` – KiCad project, Gerbers/BOM/CPL (`pcb/fab/`), ESPHome firmware (`pcb/esphome/`), generator scripts (`pcb/gen/`).
- `cad/` – FreeCAD fader model and PCBA assembly (FCStd + STEP).
- `freecad-macros/` – macros to copy into `%APPDATA%\FreeCAD\v1-1\Macro\`.
